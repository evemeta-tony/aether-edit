# docs/design/

Design material for aether-edit.

Third-party design trees land under `docs/design/ui_kits/` and are preserved
byte-exact: they are exempt from EOL normalization (see `.gitattributes`),
from the C4 prose rules, and from the filename first-line check (see
`infra/ci/first-line-exceptions.txt`). Do not reformat or "clean" anything
under `ui_kits/`.

First-party design docs arrive with the WOs that produce them, starting with
WO-014.
