# the offline source of truth the license check trusts.

# Pre-existing Go dependency gap (closed here, independent of FT-5). The go.mod
# files under services/ reference these modules but the map only carried four
# prefixes, so check-licenses.sh was already RED on main for all of them before
# this PR (Argus PR#7 M2 / Noa-verifiable). Each SPDX id below is verified from
# the module's own LICENSE file. Entries are pinned to the EXACT module path
# actually referenced (or, for a family with its own submodules, the family
# root) rather than a broad vendor prefix: a bare "github.com/aws" would
# longest-prefix-match ANY future github.com/aws/... module and silently pass
# S7 regardless of its real license, which is exactly the gate hole S7 exists
